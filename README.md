# Marco Antônio Silva Bruschi — Portfolio

> Personal portfolio showcasing full-stack engineering, API architecture, AI integrations, and real-time WebGL graphics. Built with Next.js 15, TypeScript, Tailwind CSS, Three.js, and GSAP.

---

## 🛠️ Stack & Technologies

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Standalone Output)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **3D Graphics & Shaders**: [Three.js](https://threejs.org/) (WebGL2 canvas with memory leak prevention & dispose routines)
- **Animations**: [GSAP](https://greensock.com/gsap/) (ScrollTrigger & Context cleanup)
- **Typography**: Geist Sans & Geist Mono
- **Internationalization**: Bilingual (Português / English) with instantaneous state toggle

---

## 🚀 Getting Started Locally

### Prerequisites

- Node.js 18+ installed
- npm or yarn or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/MarcoBruschi/Artisan-Portfolio.git

# Navigate into the project directory
cd Artisan-Portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Production Build

```bash
# Verify build & type checks
npm run build

# Start production server
npm run start
```
